# 更新记录

### 2026-11-27

#### 修复与优化

- 强化增量撤销与快照恢复：支持非关联字段转为关联字段后的原值还原、已删记录本的结构恢复交接，以及多次删除后任意顺序撤销时的多选关联顺序保留。
- 全量备份导入自动隔离历史撤销快照，避免跨备份误操作。
- 统一数据库初始化为干净的 v1 核心结构（`initCoreSchema`），移除历史兼容迁移与旧快照回退路径，启动零快照扫描。

### 2026-11-26

#### 修复

- 稳定随手说草稿 ID 与跨表关联令牌规范化，预览与入库阶段统一校验单选/多选必填关联，修复删草稿错绑与事务回滚缓存残留问题。
- 强化删除记录本/条目与撤销时的关联解绑、必填关联删除保护、视图配置继承保留以及筛选排序一致性。
- 撤销与恢复升级为 Schema 感知，支持按线性时间合并大规模多选关联顺序并保持索引一致。

### 2026-11-25

#### 优化

- 数据层模块化拆分为独立 Store（`libraries`、`entries`、`widgets`、`snapshots`、`backup`）与水合/关系同步模块，拆分大型页面与弹窗组件，优化列表查询与状态订阅范围。
- 完善公式引擎、校验器、JSON 解析与数据一致性单元测试，可通过 `npm test` 一键运行全部测试。

### 2026-11-24

#### 新增

- AI 建筑师支持按需设计、定制与撤销记录本视图（列表、画廊、日历、统计看板）。

### 2026-11-23

#### 新增

- 独立拆出 `library_views` 与 `library_relations` 表，支持为每个记录本按需增删、排序和定制多视图。
- 记录本设置弹窗拆分为可滑动切换的「基础 / 字段 / 视图」三标签页，新增内联日期选择器与图片大图预览。

#### 优化

- 全面升级各主页面与弹窗的视觉层级和交互体验，打磨 Android 页面切换动效、底部抽屉与滑动分段栏。

### 2026-11-22

#### 新增

- 记录详情页拆分为基础信息、附属子记录本与反向关联记录多标签页。
- AI 助手按场景区分角色与上下文（首页全能管家、本库助理、记录随行助理、统计数据分析师）。
- 可用 `pnpm build:android:release` 和 `pnpm build:android:debug` 分别生成 Release 和 Debug APK。

#### 修复

- Debug APK 可在未连接 Metro 时直接进入首页，解决了停在启动页的问题。
